# 快速拆层对比（避开 See-through 长耗时）

## 结论

无成熟「非 See-through」语义拆层项目。

| 路径 | 耗时 | 语义层 | 能否 psd2live |
|------|------|--------|----------------|
| puppet-part-splitter（连通域） | 秒～分钟 | 否 | 否 |
| 设定图裁切 + 组 PSD | 分钟 | 否 | 否 |
| See-through 768 | 约 30–40 分钟 | 是 | 是 |

连通域在不透明立绘上几乎得到整只角色，拆不出眼/嘴/发。

puppet-part-splitter 已评估并删除。
